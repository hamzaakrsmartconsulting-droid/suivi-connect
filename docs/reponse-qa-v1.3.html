2. Nouvelles fonctionnalités implémentées suite à votre revue 3 features
🔒 Blocage de compte — Sécurité
Après 5 tentatives de connexion incorrectes consécutives, le compte est automatiquement bloqué pendant 15 minutes. Une bannière orange informe l'utilisateur avec le temps restant. Le déblocage est automatique. Le compteur se réinitialise après une connexion réussie.
Connexion → saisir un mauvais mot de passe 5 fois → bannière 🔒 "Compte temporairement bloqué. Réessayez dans 15 minutes."
🗑️ Suppression de compte RGPD
Patient et médecin peuvent supprimer définitivement leur compte depuis leur page Profil. Une modal de confirmation exige la saisie du mot de passe. Si incorrect, la suppression est refusée. Si correct, toutes les données sont supprimées en cascade (suivis, médicaments, alertes, messages, RDV) et l'utilisateur est déconnecté automatiquement.
Profil → "Supprimer mon compte" → saisir le mot de passe → compte supprimé, déconnexion, redirection vers /connexion. Tentative de reconnexion → refusée.
📥 Export des données personnelles RGPD
Chaque utilisateur peut télécharger l'intégralité de ses données personnelles au format JSON depuis sa page Profil, conformément au Règlement Général sur la Protection des Données. Le fichier est nommé dynamiquement : mes-donnees-jean-dupont-2026-09-21.json
Profil patient ou médecin → "Télécharger mes données" → fichier JSON téléchargé contenant profil, suivis, médicaments, alertes, messages, RDV, ordonnances.
3. Points clarifiés Non des bugs
Point soulevé Statut Explication
Temps de chargement initial 20–50 s ℹ️ Infrastructure Cold start du serveur Render (plan gratuit) — s'arrête après 15 min d'inactivité. Une fois actif, réponses < 1 s. Ce n'est pas un bug applicatif.
Pas de notifications hors-ligne Hors scope v1 Les notifications temps réel (Socket.io) fonctionnent quand l'utilisateur est connecté. Les push notifications navigateur sont hors scope v1, documentées section 16.
Création de patient depuis l'interface Admin Hors scope v1 L'inscription se fait via /inscription uniquement. Pas d'interface admin de création en v1.
Conflits horaires dans l'agenda Hors scope v1 Pas de contrôle automatique des chevauchements de rendez-vous en v1. Documenté section 10.
Appel audio/vidéo sur Safari ℹ️ Navigateur WebRTC sur Safari nécessite HTTPS — fonctionne en production (Cloudflare). Peut échouer en local HTTP. Ce comportement est lié au navigateur Apple, pas à l'application.
